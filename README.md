## Featured Project

### RodEngine

A C++23 game engine and editor, my main long-term project. Link below.

**Main goals:** learning modular software architecture, engine design, and the modern C++ toolchain and ecosystem. Practical work with build systems, code quality, testing, and debugging.

**Engine & Editor**
- OpenGL 2D/3D rendering, batching, lighting and shadows
- ECS, scene serialization, entity/component management
- Dockable editor, viewport, gizmos and asset browser
- C# scripting via .NET, standalone runtime

**Development & Toolchain**
- CMake, MSVC / Clang, Windows & Linux
- Clang-Tidy, Clang-Format, sanitizers
- Catch2, CTest, GitHub Actions CI
